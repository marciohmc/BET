# Cassanova iGaming Studio - G-Machine

Este diretório contém o código-fonte dos jogos proprietários do Cassanova Casino.

## Objetivo
Desenvolver e gerenciar jogos independentes (Slots, Crash Games, etc.) que se comunicam com o Backend principal do Cassanova via API de Carteira Única (Seamless Wallet).

## Estrutura sugerida para análise:
- `/games`: Código-fonte das animações e motores matemáticos.
- `/engine`: Lógica comum de RNG e cálculos de RTP.
- `/api`: Middlewares de comunicação com o servidor principal.
